# Imported map sources

These source meshes came from the two archives supplied by the user and are
converted into sealed, collision-enabled GoldSrc BSP maps by
`scripts/import-map-obj.ts`.

- `small_pvp_arena/small_pvp_arena.obj` — `small-pvp-arena.zip`, Hammer-exported source mesh.
- `arena_map_v3/arena_map_v3.obj` — `fps-shooter-game-arena-map-v3.zip`, Unity-exported source mesh.

The archives did not include author or license metadata. They are preserved
here as user-supplied project assets rather than attributed to OpenStrike.
