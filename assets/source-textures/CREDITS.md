# Environment texture sources

The original 1K diffuse images in this directory are released under the
[CC0 1.0 Universal license](https://creativecommons.org/publicdomain/zero/1.0/).
OpenStrike downsamples and palette-quantizes them for the GoldSrc-compatible
arena WAD; the original files are retained here for reproducible builds.

- `concrete_floor_03_diff_1k.jpg` — [Concrete Floor 03](https://polyhaven.com/a/concrete_floor_03), Matterfield Photography and Rob Tuytel, Poly Haven.
- `brick_wall_11_diff_1k.jpg` — [Brick Wall 11](https://polyhaven.com/a/brick_wall_11), Rob Tuytel, Poly Haven.
- `corrugated_iron_02_diff_1k.jpg` — [Corrugated Iron 02](https://polyhaven.com/a/corrugated_iron_02), Jenelle van Heerden and Sergej Majboroda, Poly Haven.

`arena_orange.png` and `arena_grey.png` are AI-generated replacement
materials created for OpenStrike. They replace the flat-color images from the
user-provided `fps-shooter-game-arena-map-v3.zip` package so the imported map
has readable surface detail and lighting contrast.
